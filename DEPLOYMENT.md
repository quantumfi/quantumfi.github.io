# QuantumFi GitHub Pages Deployment

Use this folder as the root of the GitHub Pages repository.

Recommended repository name:

```text
quantumfi.github.io
```

Deploy this structure:

```text
index.html
styles.css
script.js
assets/
img/
quantumfi_finance/
quantumfi_reservoir/
quantumfi_publisher/
```

Pages:

```text
/                         Main QuantumFi landing page
/quantumfi_finance/       Finance Observatory
/quantumfi_reservoir/     Reservoir Simulator
/quantumfi_publisher/     QuantumFi Publisher
```

Do not deploy from `quantumfi_publisher/quantumfi.github.io`; that was an older nested copy.
